Blog-termux

纯静态单页面应用 — 无需 PHP / Node / Python 后端

Nginx ES Modules 零后端 离线可用 响应式

简介

基于 Nginx 运行的极简控制台，集成 系统仪表盘、 服务导航、Markdown 博客、 图片画廊 四大模块。所有内容通过 nginx autoindex 或预生成的 index.json 发现，无需任何后端运行时。

本项目衍生自 bastienwirtz/homer， 在长期使用中逐步演变为当前形态。所有 JS 使用 ES Modules 显式声明依赖， 配合 JSDoc + ESLint + Stylelint + ShellCheck 的 CI 门禁保证代码质量。

四大模块

📊
系统仪表盘
8 张卡片：设备 / CPU（含集群）/ 内存（含 SWAP）/ 储存 / 网络 / 电池 / 服务 / 运行时间，30s 轮询
🧭
服务导航
config.json 分组渲染，250ms 防抖搜索，URL 白名单安全跳转
📝
博客阅读器
三栏布局，Markdown 内联渲染 + ToC + KaTeX 数学公式 + TikZ 图表（纯客户端渲染），HTML 文章新标签页打开
🖼️
图片画廊
缩略图网格，懒加载，250ms 防抖搜索，灯箱放大（ESC / 点击背景关闭）

技术栈

  • 所有 JS 使用 ES Modules（12 业务模块 + 1 入口，import/export 显式声明依赖）
  • Markdown 渲染：marked 引擎 + 五层白名单 sanitizer + KaTeX 数学公式（按需懒加载）
  • md-viewer.js 完整 8 步管道：脚注 → 数学提取 → 解析 → XSS 清理 → 图片路径 → 锚点 → KaTeX → 灯箱绑定
  • CSS 策略：CSS 自定义属性 + 3 个响应式断点（1024 / 639 / 400px），build.sh 合并 15 个源文件
  • Service Worker：分层缓存（network-only 实时 / SWR 文章图片 / network-first 入口 / cache-first 静态）
  • 仪表盘数据：corn.sh 定时采集系统指标（零 root）→ dashboard.json → 前端每 30s 轮询 + 8s 超时
  • 文件发现：gen_index.sh 生成 index.json（Markdown/Html/Image 三目录）→ nginx autoindex 降级
  • 竞态防护：AbortController + 请求 ID 计数器，Promise.allSettled 多源容错
  • 安全：文件名 escapeHtml 转义 + URL 白名单验证 + HTML sanitizer 五重过滤

快速开始

# 1. 克隆 git clone https://github.com/lost-clouds/Blog-termux.git ~/Blog-termux # 2. 下载前端依赖（一次性，后续完全离线） cd ~/Blog-termux/lib curl -sSLO https://cdn.jsdelivr.net/npm/marked/marked.min.js curl -sSLO https://cdn.jsdelivr.net/npm/katex/dist/katex.min.js curl -sSLO https://cdn.jsdelivr.net/npm/katex/dist/katex.min.css curl -sSLO https://cdn.jsdelivr.net/npm/katex/dist/contrib/auto-render.min.js curl -sSLO https://cdn.jsdelivr.net/npm/github-markdown-css/github-markdown.min.css # 3. 配置 Nginx（参考 README 中的 server 配置块） # 将所有 /path/to/Blog-termux 替换为实际路径 # 4. 配置仪表盘定时采集（每 30 秒） # crontab 添加： # * * * * * bash ~/Blog-termux/corn.sh ~/Blog-termux/dashboard.json # * * * * * sleep 30; bash ~/Blog-termux/corn.sh ~/Blog-termux/dashboard.json # 5.（可选）生成静态索引，加速加载 bash ~/Blog-termux/gen_index.sh ~/Blog-termux # 6. 重载 Nginx 并访问 nginx -s reload # 浏览器打开 https://127.0.0.1:7443

部署要素

🖥️
Nginx
Web 服务器，提供 autoindex 目录列表和静态文件服务
⏱️
cron
定时执行 corn.sh 采集系统指标，每 30s 刷新 dashboard.json
📁
Markdown/
放入 .md 文章，博客标签页自动发现并内联渲染
📄
Html/
放入 .html 文章，博客标签页展示，新标签页打开
🖼️
Image/
放入图片，画廊标签页自动展示；thumbnails/ 和 archive/ 被跳过
📦
lib/
第三方库本地化，一次下载完全离线（marked / KaTeX / github-markdown）

数据流

gen_index.sh (可选定时) → Markdown/index.json | Html/index.json | Image/index.json corn.sh (cron 每 30s) → dashboard.json │ │ 优先: fetch index.json │ 降级: DOMParser 解析 nginx autoindex HTML ↓ Markdown/Html/Image/ ── nginx autoindex ──→ /api/md/ | /api/html/ | /api/images/ │ GET /api/dashboard ───────────────────────────────┘ ↓ dashboard.js (30s 轮询) blog.js / gallery.js 更新 8 张仪表盘卡片 → 渲染文章列表 / 图片网格

核心设计：index.json 优先 → nginx autoindex 降级。前端先 fetch 结构化 JSON（快速可靠），若索引未生成（404）则降级为 DOMParser 解析 autoindex HTML，实现零后端的文件发现。
